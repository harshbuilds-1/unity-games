Rescue Ranch

Feed the animals. Keep the rescue chain alive.

A Unity prototype by Harsh Kumar

Rescue Ranch

Best played on a computer with a keyboard. Game files load when you press Play.

Desktop keyboard recommended
The challenge

Aim / Rescue chains

Dodge incoming animals and throw food to rescue them. Consecutive feeds raise your multiplier; every fifth feed in a chain earns an emergency slow-down.

How to play

Enter: start
WASD / arrows: move
Space: throw
E: slow-down when charged
P: pause
R: restart

Click inside the game if the controls do not respond. These builds use a keyboard; touch controls are not included.

About this prototype

AI-assisted academic prototype reconstructed from Unity Create with Code course-library assets. Rescue-chain scoring and earned slow-down implement the requested original mechanics. Course assets retain their original licences.

Browser smoke tests check loading and basic controls. These are learning projects, not measured usability outcomes.
