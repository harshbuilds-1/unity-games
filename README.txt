HK / PLAY LAB
Playable Unity prototypes by Harsh Kumar

Play: https://harshbuilds-1.github.io/unity-games/
Portfolio: https://harshbuilds-1.github.io/

Games: Last Delivery, Soap Panic, Stack & Splat, Checkpoint Run, Rescue Ranch.
Desktop browser and keyboard required. Click a game, then Play.
Each game page contains controls and credits. These are learning prototypes, developed with AI assistance.

This repository contains the published browser builds and website. Unity source projects are kept locally.
Unity and course-library assets retain their original rights; this repository does not grant a blanket licence to those assets.

Hosting: GitHub Pages, main branch, repository root. All runtime files use relative paths.
Raw older builds are gzip-compressed for upload and decompressed by player.js. New builds use Unity decompression fallback.

Validation: browser loading, basic movement, pause, restart, and fullscreen checks. This is not a human usability study or a full cross-browser certification.
