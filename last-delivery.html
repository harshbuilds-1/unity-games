Last Delivery

Best played on a computer with a keyboard. Game files load when you press Play.

Desktop keyboard recommended
The challenge

Timing / Interaction

Put down your parcel to operate a switch, then collect it and cross before the gate closes. A small courier challenge about planning, state changes, and recovery.

How to play

Enter: start
WASD / arrows: move
E: pick up, drop, or use a switch
Shift: sprint with empty hands
Space: jump with empty hands
R: restart
P: pause

Click inside the game if the controls do not respond. These builds use a keyboard; touch controls are not included.

About this prototype

An AI-assisted personal academic prototype. Unity primitives and bundled UI resources. Concept, code, visuals, debugging, documentation, and functional testing were developed with AI assistance.

Browser smoke tests check loading and basic controls. These are learning projects, not measured usability outcomes.
