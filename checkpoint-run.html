Best played on a computer with a keyboard. Game files load when you press Play.

Desktop keyboard recommended
The challenge

Driving / Recovery

Drive through the cyan gates, then the gold finish. Each checkpoint adds six seconds. Watch for traffic, road edges, and crates.

How to play

Enter: start
W / up: forward
S / down: reverse
A/D: turn
Shift + A/D: strafe
P / Escape: pause
R: restart

Click inside the game if the controls do not respond. These builds use a keyboard; touch controls are not included.

About this prototype

AI-assisted academic arcade-driving prototype based on Unity Create with Code course assets and beginner programming concepts. Original asset rights remain with their owners.

Browser smoke tests check loading and basic controls. These are learning projects, not measured usability outcomes.
